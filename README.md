# Планы на день

Небольшое адаптивное приложение для управления задачами. Проект работает без сервера и сохраняет список в `localStorage`, поэтому задачи не исчезают после обновления страницы.

## Ссылки

- **Демо-сайт:** [odswebdev.github.io/ai-todolist](https://odswebdev.github.io/ai-todolist/)
- **Исходный код:** [github.com/odswebdev/ai-todolist](https://github.com/odswebdev/ai-todolist)

## Возможности

- добавление задач через форму или клавишу Enter;
- отметка задач выполненными;
- редактирование названия задачи с проверкой пустого ввода;
- удаление отдельных задач с возможностью отмены в течение 5 секунд; таймер отмены приостанавливается при наведении указателя или фокусе внутри уведомления;
- синхронизация списка между вкладками одного браузера;
- фильтрация: все, в работе, готово;
- сводный прогресс выполнения с доступным progressbar-состоянием;
- очистка всех выполненных задач;
- сохранение состояния в браузере;
- адаптивная вёрстка для телефона и компьютера;
- доступность: клавиатурная навигация, focus-visible, aria-статусы, области нажатия 44×44 px;
- безопасная обработка пользовательского ввода и повреждённых данных хранилища;
- ограничение до 500 задач для стабильной работы интерфейса.

## Запуск

Откройте `index.html` в браузере или запустите встроенный статический сервер из папки проекта (требуется Node.js 20 или новее; рекомендуется Node.js 24 LTS):

```bash
node tests/server.cjs
```

После этого откройте `http://127.0.0.1:4174`. Сервер использует только встроенные модули Node.js и слушает только локальный адрес. Он обслуживает лишь `/`, `/index.html`, `/styles.css`, `/script.js` методом GET или HEAD; для `/favicon.ico` возвращает 204.

## Использованные AI-инструменты

AI-инструмент, указанный автором проекта: **Claude Code Fable 5.2**. AI использовался для реализации интерфейса, ревью и подготовки автоматических тестов. Задачи ставились итеративно: основной функционал → оформление и адаптивность → ревью → исправление ошибок → регрессионные тесты. Текущие доработки и проверки выполнены через AI-помощника в DeepSeek Harness. Браузерные и ручные проверки описываются отдельно по фактическому выполнению.

## Автоматические проверки

Требуется Node.js 20 или новее; рекомендуется Node.js 24 LTS; Python для тестов не нужен. Playwright автоматически запускает `node tests/server.cjs` на `127.0.0.1:4174`. Установка зависимостей и браузера для E2E:

```bash
npm ci
npx playwright install chromium
npm test
npm run test:e2e
```

`npm test` запускает модульные тесты логики. Playwright E2E запускаются в Chromium для desktop- и mobile-профилей и проверяют добавление, выполнение, фильтрацию, прогресс, редактирование и валидацию, отмену удаления, очистку выполненных, синхронизацию вкладок, клавиатурное добавление и переполнение на ширине 320 px. Регрессионные сценарии проверяют лимит 500 задач при отмене удаления, порядок восстановления после добавления, сохранность нескольких черновиков, паузу и возобновление таймера отмены, предупреждения при отказе хранилища. Отдельные Node-тесты проверяют разрешённые маршруты статического сервера, MIME-типы, GET/HEAD и запрет обхода путей. Также выполняется axe-core аудит WCAG 2.2 A/AA. Автоматический аудит не заменяет проверку с реальным скринридером и ручной визуальный осмотр.

Последний полный прогон: **27 Node-проверок и 34 Playwright-проверки прошли без ошибок**. Браузерные проверки выполнены в desktop Chromium и эмуляции Pixel 7; это не проверка на физическом телефоне и не покрытие Safari/Firefox.

Перед публикацией проверьте с NVDA/VoiceOver фокусный порядок и озвучивание статусов, увеличение масштаба до 200%, а также отсутствие горизонтальной прокрутки при ширине 320–1440 px.

## Примечания по хранению

Это клиентское приложение для одного пользователя: данные хранятся только в `localStorage` текущего браузера и не синхронизируются между устройствами. Проект не использует авторизацию или backend. При недоступном или переполненном хранилище интерфейс продолжает работать в рамках текущей сессии.

Незавершённые черновики редактирования сохраняются при переключении фильтров и действиях с другими задачами. Они хранятся только в памяти текущей вкладки и не переживают перезагрузку страницы (reload). Сохранённые названия задач остаются в `localStorage`.

Отмена удаления не восстанавливает задачу, если в списке уже 500 задач: лимит нельзя превысить восстановлением. Можно освободить место через «Удалить готовые» и повторить отмену, пока исходная отмена доступна. Удаление ещё одной отдельной задачи заменяет предыдущую отмену. Наведение указателя или фокус внутри уведомления отмены ставит его таймер на паузу.
